## ✨ Sobre o NextPlay

O NextPlay nasceu para resolver um problema simples:
"Eu quero jogar alguma coisa diferente, mas não sei o quê."

Em vez de navegar por listas enormes de jogos, o usuário descobre
novos títulos através de um feed vertical de trailers...
